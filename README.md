# Webscraping - Aula BeautifulSoup

Exemplos e exercícios da aula sobre BeautifulSoup.

## Como usar

1. Ative o ambiente virtual (PowerShell):

```powershell
cd C:\Users\User\Downloads\webscraping
.\.venv\Scripts\Activate.ps1
```

2. Instale dependências:

```powershell
pip install -r requirements.txt
```

3. Execute o script principal:

```powershell
python aula_sobre_beautifulSoup.py
```

## Arquivos relevantes

- `aula_sobre_beautifulSoup.py` — script de exemplo
- `Pagina Hashtag.html` — arquivo HTML usado no exemplo

## Observações

O repositório já contém um ambiente virtual (`.venv`) local que não deve ser versionado. Veja `.gitignore` para mais detalhes.
